# nginx

The deployment's only public surface. Every request from a browser or a phone
arrives here, and nothing else publishes a port a participant or a researcher can
reach. Prose: [`nginx/README.md`](../../nginx/README.md).

The route table itself is in
[architecture.md](../dev/architecture.md#what-nginx-does-with-a-request), sorted by
what the caller proves.

---

## What owns what

| Concept | File |
| --- | --- |
| Every route, over plain HTTP | [`http.conf`](../../nginx/http.conf) |
| The same routes, with TLS and the redirect | [`https.conf`](../../nginx/https.conf) |
| The landing page a researcher opens | [`index.html`](../../nginx/index.html) |
| The backup and restore page | [`backup.html`](../../nginx/backup.html), [`assets/backup.js`](../../nginx/assets/backup.js) |
| The page shown while the wizard starts | [`setup-loading.html`](../../nginx/setup-loading.html) |
| Styles and scripts those pages load | [`assets/`](../../nginx/assets) |

`study-key.conf` is generated by the deploy and mounted as `00-study-key.conf`. The
prefix is load order: nginx reads `conf.d` alphabetically, so the key map exists
before `default.conf` uses it. It is not in git.

## Two configurations, one mounted

The deploy mounts one of the two as `default.conf`, chosen by the study's protocol:

```yaml
- ./nginx/${PROTOCOL:-http}.conf:/etc/nginx/conf.d/default.conf:ro
```

Both carry the same routes. **A route added to one and not the other is a
deployment that works until somebody turns on TLS.** The HTTPS file adds only the
transport: a `listen 80` server that redirects, a `listen 443 ssl` server with the
certificate paths, and `Strict-Transport-Security`.

## The two idioms every location uses

**Upstreams go through a variable.** `set $name http://service:port;` before
`proxy_pass $name/...` defers the DNS lookup to request time, so nginx starts even
while a container behind it is still coming up.

**A phone proves a study key, a researcher proves a session.** Researcher routes
carry `auth_request /auth/validate`; phone routes compare the request's key against
`$study_key` from the generated map; a few routes are public.

The key comes from `secrets.token_urlsafe`, whose alphabet includes `-`, so a
pattern matching it is `[\w-]+` and never `\w+`.
